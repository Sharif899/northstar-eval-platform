Northstar Eval Platform

Measure whether the support assistant is reliable, accurate and safe — and catch regressions before release. Scores are deterministic rubric checks, not a judge model; flagged results go to a human reviewer.

1. Upload a dataset and its knowledge base

A .jsonl or .csv file. Each example needs an id, a question, a reference answer, source document ids and an expected behaviour.

Then upload the knowledge base the assistant answers from — a knowledge_base.json file with one entry per source document (id, title, text). Every citation is checked against these documents, so an evaluation cannot run until the knowledge base is here.

3. Runs

4. Compare two runs

5. Human review queue

Results the scorer flagged — borderline scores, sharply disagreeing metrics, or a low metric. A reviewer records agree or disagree with a corrected score and a note.
